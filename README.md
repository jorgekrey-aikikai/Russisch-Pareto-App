# Russisch Trainer Offline – Version 3

## Inhalt
- index.html
- vocab.js
- manifest.json
- service-worker.js
- icon.svg

## Funktionen
- komplett offline
- keine API, kein API-Key
- Stufen: 25 / 50 / 100 / 250 / 500
- lokaler Fortschritt
- JSON Export / Import
- einfache Wiederholungslogik
- GitHub Pages geeignet
- installierbar als PWA

## GitHub Pages
1. Neues Repository anlegen
2. Alle Dateien ins Hauptverzeichnis hochladen
3. Unter Settings > Pages:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
4. Die GitHub-URL auf dem Handy öffnen
5. Zum Startbildschirm hinzufügen

## Hinweis
